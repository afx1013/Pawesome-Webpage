# Pawesome Webpage

Pawesome is a front-end website for a fictional pet adoption center. The site spans 6 pages — a home page, pet browsing/selection page, adoption form, volunteer sign-up, about us, and donation page — and is built with HTML, CSS, and a bit of JavaScript. Responsive design, adaptive to different browsers and screen size. 

## Pages
- **Home** – Landing page for the Pawesome brand
- **Get Involved** – Sign up to volunteer with Pawesome
- **Find a Pet** – Browse available cats and dogs for adoption
- **Adoption Form** – Apply to adopt a pet
- **About Us** – Learn about the Pawesome mission
- **Donate** – Support the cause

## Tech Stack
- HTML
- CSS
- JavaScript
